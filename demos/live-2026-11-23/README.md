## Run sequence
1. Initialize shell (live boot diagnostics)
2. Morse synth and SHA-256 / Base64 on example input
3. USGS live quake feed and ISS live position
4. Cloudflare DNS lookup for `example.com`, then CIDR calculator
5. Infinite text wall — stamp, color, write and pan
6. Search query compiler using a public NASA example
7. File magic-byte, entropy and hex inspection of a local PNG
8. URL tracker stripping and punycode warning
9. Steganography encode/decode, local AES-GCM lock/unlock
10. Interactive CLI commands and return to Signal

The end cards/section title overlays are editorial. Live maps, DNS values and ISS data reflect capture time only. No claims of real-time status after recording. No secret keys or credentials were used in demonstrations.
